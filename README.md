# IPv4 子网规划台

一个纯本地的 IPv4 子网规划工具：在互不重叠的根网段中，以树形地址空间可视化管理命名保留段与子网分配，支持按主机数自动申请最小可用子网、迁移预演、撤销重做与规划 JSON 导入导出。

技术栈：**React 18 + TypeScript + Vite + ipaddr.js**，无任何后端依赖，数据完全保存在浏览器内存中。

## 快速启动

### 方式一：Docker Compose（推荐，单条命令）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**

### 方式二：本地开发

```bash
npm install
npm run dev
```

启动后访问：**http://localhost:5173**

### 其他命令

```bash
npm test            # 运行规划引擎单元测试（vitest）
npm run build       # 类型检查 + 生产构建（输出 dist/）
npm run preview     # 预览生产构建（http://localhost:4173）
```

## 功能说明

### 根网段
- 添加多个**互不重叠**的根 CIDR（如 `10.0.0.0/8`、`192.168.0.0/16`），未对齐网络地址或相互重叠会被拒绝；
- 每个根网段显示地址总量与利用率进度条。

### 地址空间树
- 每个根网段以二叉树形式展示地址空间：`空闲`（绿色）、`部分占用`（黄色）、`已分配`（蓝色）；
- 空闲块自动按伙伴块（buddy）递归合并——释放分配后，可组成上级 CIDR 的相邻空闲块立即合并为更大的空闲节点；
- 部分占用的节点可展开/折叠，逐层下钻到具体分配。

### 分配
- **命名保留段**：指定名称 + CIDR，校验对齐、越界与重叠；
- **按主机数申请**：输入所需主机数，自动计算最小前缀（网络地址与广播地址不计入容量；/31 按 RFC 3021 计 2，/32 计 1），并在全部根网段（或指定根网段）中安置到**最低可用地址**；
- 所有分配强制对齐 CIDR 边界，越界与重叠一律拒绝；
- 每条分配展示网络地址、广播地址、可用主机数与所属根网段。

### 迁移预演
调整根网段（编辑/删除）或分配容量时，系统先进行**迁移预演**：

1. **可保留项原位不动**（容量未变、仍在新根网段内且不与其他保留项冲突）；
2. 其余项按**网段从大到小、原地址升序**依次安置到**最低可用地址**；
3. 预演结果以表格展示（原位保留 / 迁移 / 无法安置）；
4. **存在无法安置项时确认按钮禁用**；否则确认后整批**原子应用**（单条历史记录，可一次撤销）。

### 生成 DHCP 地址池
在**分配清单**中，每条「子网」分配提供「生成 DHCP 地址池」操作（保留段不提供）：

- 弹窗中**逐行输入需要排除的单个 IPv4 地址或对齐 CIDR**（如 `10.0.0.1`、`10.0.0.128/26`），空行自动忽略；
- 排除项必须**完整位于所选子网内**；任一行非法（格式错误、CIDR 未对齐）或越界，会**逐行显示错误（含行号）且不生成任何结果**；
- 地址范围规则：`/0`～`/30` 自动排除网络地址与广播地址；`/31`、`/32` 沿用现有可用主机规则（RFC 3021 计 2、主机路由计 1）；
- 计算时先将相互**重叠或相邻的排除区间合并**，再用**区间运算**扣除得到剩余地址——全程只做 `[start, end]` 区间合并/扣除，**不逐地址枚举**，支持 `/0` 等大网段；
- 输出**数量最少**的 `起始 IP - 结束 IP` 连续范围，支持**一键复制**（`navigator.clipboard`，并带降级方案）；
- 该操作是**纯计算**：不修改规划数据，也不产生撤销/重做历史。

### 撤销 / 重做
- 工具栏按钮或快捷键：`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` 重做；
- 所有变更（含迁移、导入、清空）均进入历史栈。

### 导入 / 导出
- **导出**：下载当前规划为 JSON 文件；
- **导入**：选择 JSON 文件，完整校验（格式、对齐、根网段重叠、分配越界/重叠、容量一致性）通过后才替换当前规划，失败会列出全部错误；
- 「载入示例」可一键填充演示数据。

```

│   └── main.tsx
└── package.json
```

## 容量计算规则

| 前缀 | 地址总数 | 可用主机 |
| ---- | -------- | -------- |
| /24  | 256      | 254      |
| /30  | 4        | 2        |
| /31  | 2        | 2（RFC 3021 点对点链路） |
| /32  | 1        | 1（主机路由） |

即常规前缀可用主机 = 2^(32-前缀) − 2（去掉网络地址与广播地址）。
